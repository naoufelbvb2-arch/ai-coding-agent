## قواعد عدم الافتراض

- **مرشح لغوي ≠ تصحيح نافذ.** جميع الروابط المحسوبة تحمل وسم UNREVIEWED، ولا تُستخدم كحكم استبدال.
- **العقد الجديد ≠ إلغاء العقد القديم.** الأدلة الجديدة تصف ما يجب أن يتعايش مع النوع السابق؛ لا تُسقط حقولًا أو تُضيف Adapter تلقائيًا.
- **حماية موثقة ≠ تنفيذ ثابت.** لا توجد محاكاة معاملات إنتاجية، ولا commit عبر العالم الخارجي.
- **صحة بصمة ≠ صحة الدمج الدلالي.** شرط تجميد L0–L7 يظل مراجعة كل استبدال/تقييد ضمن النص النافذ.
