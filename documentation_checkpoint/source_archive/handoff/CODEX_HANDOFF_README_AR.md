# تسليم مشروع AI Coding Agent إلى Codex

تتضمن هذه الحزمة:

1. `AI_CODING_AGENT_OPERATIVE_NORMATIVE_CLOSEOUT.zip`: أحدث أرشيف للمشروع كاملاً، نُسخ كما هو دون تعديل.
2. `CODEX_PROMPT_AI_CODING_AGENT.md`: نص المهمة المتفق عليه بصيغته الكاملة.
3. `SHA256SUMS.txt`: البصمات للتحقق من نقل الملفات دون تغيير.

## الاستخدام

- نزّل حزمة التسليم إلى جهازك وفك ضغطها.
- افتح مجلد عمل جديد للمشروع في Codex على جهازك.
- فك ضغط `AI_CODING_AGENT_OPERATIVE_NORMATIVE_CLOSEOUT.zip` إلى مجلد العمل.
- افتح `CODEX_PROMPT_AI_CODING_AGENT.md` في Codex أو انسخ نصه إلى جلسة Codex، وحدد مسار مجلد المشروع المحلي.
- اطلب منه تنفيذ **Stage A / First checkpoint فقط**؛ ينبغي أن يتوقف لنعتمد جرد المصادر وخريطة ملكية الطبقات قبل تعديل الوثائق.
- قبل تنفيذ Stage E، تأكد من وجود مستودع GitHub لـAI Coding Agent وضبط remote الصحيح؛ لا تفترض أن مستودعًا موجود بالفعل ولا تدفع أي تغييرات إلى `main` قبل الموافقة.

## ملاحظة

هذه الحزمة جاهزة للنقل اليدوي إلى Codex، لكنها لم تُرسل إلى جلسة Codex محلية أو إلى GitHub تلقائياً.
